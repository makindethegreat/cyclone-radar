# Cyclone Radar

Cyclone Mag's editorial discovery workspace: story ideas, trackers, and research projects.

## MVP
- Static single-page app
- Story discovery, category filters, search
- Story Bank (saved ideas)
- Trackers and Research Lab
- Local browser persistence
- JSON export

## Run locally
Open `index.html` in a browser.

## Deploy
Import this repository into Vercel. Framework preset: **Other**. Build command: leave blank. Output directory: `.`.
The included `vercel.json` routes requests to the single-page app.

## Important
Current story cards are sample editorial prompts, not live news or verified signals. Data is saved in the browser's local storage and is not shared between devices yet.
